# Навигатор ПП РФ №719 — для Codex и других агентов

Полный контекст проекта живёт в **[CLAUDE.md](CLAUDE.md)** — прочитай его целиком ДО любой работы:
стек, структура репозитория, принципы, текущий статус, ветки и рабочий процесс. Оперативное «где
остановились и что дальше» — [docs/NEXT_SESSION.md](docs/NEXT_SESSION.md), задачник в порядке
исполнения — [docs/BACKLOG.md](docs/BACKLOG.md).

Этот файл — намеренно **указатель, а не копия**. До 07.09.2026 здесь лежала полная копия `CLAUDE.md`
с заменой имени инструмента; две копии одного текста разъезжаются, а проект уже платил за «две
таблицы про одно» (уроки ревью записаны в `CLAUDE.md`). Правила одни для всех агентов:

- **ИИ — черновик, вердикт — за экспертом ТПП.** Ответ системы — предварительный анализ.
- **Тесты гонять документированной командой, БЕЗ `PYTHONUTF8=1`:**
  `.venv\Scripts\python -m unittest discover -s tests` — с форсированным UTF-8 батарея зеленеет
  там, где документированная среда падает.
- **Правки → `dev` → PR в `main` → тег → выкатка.** Бой (`prod`) руками не трогать; чек-лист выкатки —
  `docs/REVIEW_TZ.md §1а`, эталонный скрипт — `scripts/deploy/deploy.sh`.
- **Персональные данные** (выгрузки с боевого сервера) в репозиторий не попадают никогда — 152-ФЗ.
- **Секреты** только в `.env` (шаблон `.env.example`), в git не коммитятся.
