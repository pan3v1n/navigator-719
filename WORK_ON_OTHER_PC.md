# Как продолжить работу над проектом на другом ПК

Короткая инструкция: открыть репозиторий на новом компьютере и продолжить
редактирование кода через Claude Code. Полная настройка окружения — в [SETUP.md](SETUP.md).

---

## Что нужно установить один раз на новом ПК

| Программа | Где взять | Проверка |
|---|---|---|
| **Git** | [git-scm.com](https://git-scm.com) | `git --version` |
| **Python 3.11+** | [python.org](https://python.org) | `py -3 --version` |
| **Claude Code** | [claude.ai/code](https://claude.ai/code) | `claude --version` |

---

## Первый запуск на новом ПК (5 минут)

### 1. Скачать репозиторий
```powershell
cd C:\Users\<ВашеИмя>\Desktop
git clone https://github.com/pan3v1n/navigator-719.git
cd navigator-719
```

### 2. Настроить окружение Python
```powershell
py -3 -m venv .venv
.venv\Scripts\pip install --only-binary :all: -r requirements.txt
```

### 3. Создать файл секретов
```powershell
copy .env.example .env
```
Открыть `.env` в блокноте и вставить `DEEPSEEK_API_KEY` (взять с platform.deepseek.com).

> 💡 Этой настройки хватает, чтобы **редактировать код** через Claude Code. Чтобы
> **запустить сервис**, нужны ещё Qdrant, индексация базы и модель эмбеддингов **e5 (~2 ГБ)** —
> всё это описано в [SETUP.md](SETUP.md) (Шаги 4–5). Модель и данные Qdrant **локальны и не
> синхронизируются git** (как и `.env`) — на новом ПК они скачиваются/строятся заново.

### 4. Включить автопуш (чтобы изменения сами улетали на GitHub)
Хук `post-commit` пушит **текущую ветку** и пропускает экспериментальные `exp/*`.
Канонический текст хука — в [docs/BRANCHING.md](docs/BRANCHING.md) (там же — модель веток
`main`/`dev`/`exp` и предупреждение «не затирать блок graphify»).

### 5. Запустить Claude Code
```powershell
claude
```
Claude Code сам прочитает `CLAUDE.md` и `ROADMAP.md` — получит весь контекст проекта
и сможет продолжить работу с любой незавершённой задачи.

## Каждый раз когда садитесь за работу

### В начале — забрать свежий код:
```powershell
cd C:\Users\<ВашеИмя>\Desktop\navigator-719
git pull
```

### Работаете через Claude Code:
```powershell
claude
```

### В конце — сохранить и отправить изменения:
```powershell
git add .
git commit -m "что сделали"
```
Если включён автопуш (шаг 4) — `git push` произойдёт сам.
Если нет — выполните вручную:
```powershell
git push
```

---

## Важные правила работы с нескольких ПК

1. **Всегда делайте `git pull` перед началом работы.**
   Иначе на разных ПК разойдётся код и придётся разбираться с конфликтами.

2. **Всегда делайте `git push` (или коммит с автопушем) в конце.**
   Иначе на другом ПК не будет ваших последних изменений.

3. **Файл `.env` не синхронизируется** (он в `.gitignore` для безопасности).
   На каждом новом ПК его нужно создать заново из `.env.example`.

4. **Автопуш-хук не синхронизируется** — настраивается заново на каждом ПК (шаг 4).

## Если что-то пошло не так

**`git pull` ругается на конфликты:**
Значит на этом и другом ПК менялись одни и те же файлы. Напишите Claude Code
«помоги разрешить конфликт git» — он разберётся.

**Claude Code не видит контекст проекта:**
Убедитесь что запускаете `claude` именно из папки `navigator-719`
(где лежит `CLAUDE.md`), а не из другой директории.

**Забыли запушить с прошлого ПК:**
Зайдите на тот ПК, выполните `git push`. Или начните работу там же.
