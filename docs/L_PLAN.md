## 3. Почему такой порядок

1. **`L8-1` первым.** Всё нужное уже на бою (§6 ТЗ команд), от `L3` и `L4` он не зависит, путь ответа не меняет,
   окна недоступности не требует. Это единственная ближайшая задача с видимым результатом. Заодно закрывает
   маршрутный пробел: «Подготовка к экспертизе» в «Авто» уходит в товарную ветку (проверено 02.11 на текущем коде).
2. **`L8-1` после гейта `1.0`, а не до.** Шаги 5–8 очереди уже идут, переставлять их незачем. Если нужна
   демонстрация раньше, `L8-1` можно взять и до гейта: генерацию он не трогает.
3. **`L5` остаётся перед `L6`.** Иначе число из материала будет объявлено подтверждённым нормой (`DUAL_CORPUS_TZ §3.1`).
4. **Корпус ТПП раньше папок.** Загрузка офлайн, файлы проходят через нас, ПДн и коммерческую тайну контролирует
   проект. Папки берут из этого этапа готовое: коллекцию, замороженный `avgdl`, три исхода, пометку «не норма».
5. **Если материалов ТПП не будет,** этап 3 сводится к `L5` и техническому ядру `L6` (коллекция, режим, `avgdl`):
   на них опирается этап 4. Содержательной ценности у этапа тогда нет, и это надо понимать заранее.
6. **Чек-листы последними.** Их нет в макете. Без файлов проверять нечего, а файл с правилами в репозитории не снимает
   заявленную проблему «для правила нужен коммит». Было `P0` рядом с `L8`; перенесено решением этого плана, `Р11` может вернуть их или снять.

## 6. Этап 4: что макет не определяет

Макет статичен: у папок и «Прикрепить файл» нет логики, только вид. Решения плана, чтобы этап можно было оценить:

* файл из поля ввода попадает в папку беседы, она создаётся автоматически; второго механизма хранения нет;
* папку видит только владелец учётки; общие папки организации вне плана;
* оригинал файла не хранится, только извлечённый текст фрагментов;
* скан без текстового слоя — честный отказ, OCR вне плана (принцип №3);
* до кода — замер на боевом железе: время индексации 100 фрагментов и p50 ответа в это же время. Из окон `test41`
  выходит ~2–9 минут на файл при всех ядрах в работе (`embeddings.py`), на реальных файлах это не мерилось.
