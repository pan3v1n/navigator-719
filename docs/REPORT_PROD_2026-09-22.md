### 4.2. Разбор исправлений экспертов (сверено с корпусом)

**① HIGH — подкод ОКПД2 не наследует групповую позицию приложения.** Один диалог, ~20 реплик,
отзыв о диалоге: «ИИ путается в показаниях… НЕ находит код в приложении, хотя он есть».
- «Н-бутан очищенный», 20.14.11.**112**. В разделе XXI есть групповая позиция **20.14.11.110** <11>
  «Углеводороды ациклические насыщенные», а 20.14.11.112 «Бутан» — её подкод по ОКПД2. Система
  сначала отнесла товар к чужой позиции. Когда эксперт прямо спросил, можно ли применять требования
  20.14.11.110, система ответила **«нет, подменять требования нельзя»**.
- «Хладон», 20.14.11.**122** («Пропен (пропилен)»). Есть групповая **20.14.11.120**
  «Углеводороды ациклические ненасыщенные». Ответ ушёл в «Катализаторы гидроочистки» и
  рассуждал про «код 20».
- Оба исправления экспертов («рассматривается по требованиям группы 20.14.11.120»,
  «должен рассматриваться по требованиям углеводородов») **совпадают с иерархией ОКПД2 и
  текстом приложения**.
- Класс: подъём девятизначного подкода к групповой позиции `…0` того же уровня. Причину в коде
  не диагностировал. Кандидаты: лукап по префиксу/иерархии для позиций со сноской и пустой ячейкой
  требований (`R6`, `inheritance.py`). **Нужно отдельное issue с замером радиуса по всем групповым
  позициям `…0`.**

**② «Полотенца» без кода** — ответ ушёл в продукцию из бумажной массы. Эксперт: код 13.92.14
«Бельё туалетное и кухонное», и он есть в приложении (подтверждено). Ретрив по бытовому слову
не находит текстильную позицию.

**③ «Шкаф управления наружным освещением 27.12.31.000»** — ответ «прямого совпадения нет».
Эксперт: ближайшее совпадение — позиции «из 27.12.31» (распределительные шкафы), они в
приложении есть. Оценка эксперта: ответ некорректен.

**④ Порог для закупок** — эксперт дописал: «порог указан в примечании 5». Ответ его не привёл.

**⑤ «Бедренная ножка SL-Stem», 32.50.22.110** — оценка 1. В приложении 32.50.22.110 встречается
только как «из 32.50.22.110» в ячейке протезов конечностей. Итог «подходящей позиции нет» может
быть верным, но **кандидатами предложены позиции судостроения**, что для эксперта выглядит как
сбой. Вердикт по существу — за экспертом.

**⑥ Процедурные вопросы уходят товарной веткой** — «как подтвердить требование о налоговом
резиденте», «как подтвердить наличие лабораторий» получили `low_relevance` и ответ по карточке
товара. Это известный класс `P3-1` #131 (добор откачен в `0a1b341`); на бою подтверждается живыми
вопросами.
