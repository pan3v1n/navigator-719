## Правила на всю сессию

1. **Ничего не коммитить и не пушить**, ветки не трогать. Если `git status` в клоне стал
   грязным, это дефект шага: остановись и разберись.
2. **Бой не трогать.** К серверу допустимы ровно две вещи: `ssh … 'echo ok'` для проверки ключа
   и HTTPS-запрос `/ping`. Никаких выкаток, `docker` на сервере, правок файлов. Канал режет SSH
   по **частоте** подключений (DPI), поэтому подключения экономь и не повторяй в цикле.
3. **Работай через Bash-инструмент (Git Bash) и с абсолютными путями.** Файлы с кириллицей правь
   инструментами Edit/Write: Python, читающий скрипт из stdin, портит кириллицу (cp1251).
4. **Секреты не печатай.** Значение `DEEPSEEK_API_KEY` проверяй только на непустоту.
5. **Что делает владелец сам** — проси выполнить с префиксом `!` в поле ввода и жди: вход в
   GitHub, пароль SSH-ключа, установщики с окном UAC. Программы ставь только после «да» владельца.
6. **Долгие шаги** (батарея, индексация) — в фон, с выводом в лог **вне** репозитория
   (`D:\navigator-719-setup-logs\` — создай её первым делом). По одному: батарея и индексация
   вместе дают ложные падения.
   Результат — то, что в логе, а не уведомление.
7. **Каждый шаг заканчивается проверкой.** Провалилась — остановись, покажи владельцу, что
   именно и почему. Не чини вслепую и не пропускай молча. В отчёте у каждого шага один из трёх
   исходов: ✅ сделано и проверено · ❌ не вышло (почему) · ⏭ пропущено (почему).
8. **ПДн (152-ФЗ):** если в папке переноса окажется `pii/`, её содержимое никогда не кладётся
   в репозиторий — только в папку вне него (например `D:\navigator-export\`).

## Шаг 2. Клон

Репозиторий приватный, поэтому сначала вход:
1. Владелец: `! gh auth login` (GitHub.com → HTTPS → войти через браузер). Затем ты:
   `gh auth setup-git`, чтобы git брал учётные данные из gh. Без gh `git clone` сам откроет
   окно входа Git Credential Manager — тоже годится.
2. `git clone https://github.com/pan3v1n/navigator-719.git D:/navigator-719`
3. Авторство коммитов возьми из истории, не придумывай. Нужен обычный коммит, не merge: у
   merge-коммитов, слитых через GitHub, адрес бывает noreply.
   `git -C D:/navigator-719 log -1 --no-merges --format='%an%n%ae' origin/dev` → `git config
   user.name` и `git config user.email` **локально в клоне**.

Проверка: `git -C D:/navigator-719 log --oneline -1`; коммит из `.source_head` есть в клоне
(`git cat-file -e <sha>^{commit}`). `git config --get core.autocrlf` — сообщи значение (на прежнем
ПК было `true`, на нём построены записи о сборке пакетов выкатки).

## Шаг 8. SSH-ключ к боевому серверу

0. **Сначала проверь, нет ли ключа уже:** `ls ~/.ssh/id_ed25519.pub`. Есть — **новый не создавай**:
   `ssh-keygen` спросит «Overwrite?», и перезапись сделает ключ, уже добавленный на сервер,
   бесполезным. Покажи отпечаток (`ssh-keygen -lf ~/.ssh/id_ed25519.pub`) и спроси владельца,
   добавлен ли он на сервер; если да — сразу к п. 3. _(21.10.2026 так и было: ключ `main-pc`,
   `SHA256:wfjbJBG2XLL05OZpYCH1N8J2hKB6FiF9oN24OkLmsl8`, создан на основном ПК и добавлен на сервер
   с прежнего.)_
1. Ключа нет — владелец: `! ssh-keygen -t ed25519 -C "main-pc"`. Пароль ключа — его выбор; без
   пароля допустимо, если ПК личный.
2. Покажи владельцу содержимое `~/.ssh/id_ed25519.pub` (публичный ключ, не секрет) и попроси
   добавить его на сервер **с прежнего ПК**, где доступ уже есть:
   `cat main-pc.pub | ssh dan_tpp_srv@77.241.30.132 "cat >> ~/.ssh/authorized_keys"`. Или пусть
   вставит ключ в сессию Claude на прежнем ПК с просьбой добавить. Жди подтверждения.
3. Хост-ключ — без доверия «на слово»: `ssh-keyscan -t ed25519 77.241.30.132` во временный файл →
   `ssh-keygen -lf` по нему. Отпечаток **обязан** совпасть с
   `SHA256:SWnSbRBwVtpZST18NLvOaXU+gAObHnYja4E1MMT+cjM`; только тогда допиши строку в
   `~/.ssh/known_hosts`. Не совпал — ❌ и стоп: соединение перехвачено или адрес не тот.
4. Проверка: `ssh -o BatchMode=yes dan_tpp_srv@77.241.30.132 'echo ok'` → `ok`. Если у ключа
   пароль, BatchMode не пустит — пусть владелец выполнит `! ssh dan_tpp_srv@77.241.30.132 'echo ok'`.
   **Больше к серверу не подключайся.**
