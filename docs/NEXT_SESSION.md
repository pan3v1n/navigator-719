## Среда / как продолжить

- Локальный Qdrant: `Start-Process 'C:\Program Files\Docker\Docker\Docker Desktop.exe'` → контейнер
  `qdrant` поднимется сам (~1–2 мин). Проверка: `curl http://localhost:6533/collections`.
- Тесты (офлайн): `.venv/Scripts/python.exe -m unittest discover -s tests`
- Диагностика данных: `.venv/Scripts/python.exe scripts/diag_orphan_requirements.py`
  (`--fragments` / `--inheritance` перегенерируют файлы данных детерминированно).
- ⚠ Сеть рваная (DPI); длинные коннекты к DeepSeek/SSH роняются — ретраи 3–5 попыток.
- ⚠ На Windows для скриптов с кириллицей: `PYTHONUTF8=1 PYTHONIOENCODING=utf-8`.
