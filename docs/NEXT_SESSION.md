## План на завтра

### 1. Перед деплоем — прогнать то, что не прогонялось (нужен Qdrant, ~1 ч)

```bash
# поднять Docker Desktop → контейнер qdrant стартует сам (~1-2 мин)
curl http://localhost:6533/collections
.venv/Scripts/python.exe scripts/load_kb.py            # переиндексация: R28 (section_title) + R9 (sparse)
.venv/Scripts/python.exe scripts/eval_retrieval.py     # ГЛАВНОЕ: R9 — единственная правка, способная сдвинуть ретрив
.venv/Scripts/python.exe scripts/eval_answers.py       # faithfulness после R6/R7/R8
```
⚠ **R9 меняет sparse-индекс на полный текст** — документы до 13 882 токенов теперь совпадают с
бо́льшим числом запросов. Нормировка BM25 по длине (`b=0.75`) для этого и нужна, но подтвердить
должен замер, а не рассуждение. Если recall@1 просел — откат флагом `--full-text` не поможет,
нужно вернуть `sparse_text_fn=build_embedding_text` в `index_all`.

### 2. Живой прогон движка на контрольных вопросах (~30 мин)

Проверить глазами то, что менялось и в тестах покрыто только юнитами:
- позиция с наследованием — «Автокраны» (29.10.51): требования группы + **атрибуция** к
  «Краны грузоподъемные стрелкового типа»;
- позиция R29 — «Хладон-218»: пометка «СПИСОК ОПЕРАЦИЙ НЕПОЛНЫЙ», модель НЕ делает вывод о пороге;
- модель «перечень» — «Гидротермокостюмы»: «Порог: не предусмотрен», а не «в контексте не указан»;
- обязательные требования из `component` (права на КД/ТД, сервисный центр) видны в ответе;
- экспорт диалога в md/txt/json — пометка «ИИ — черновик» на месте.

### 3. Пакетный редеплой (когда владелец даст добро; ~1 ч)

**Сверять по чек-листу [REVIEW_TZ §1а](REVIEW_TZ.md)**, там же статусы. Ключевое:
- ⚠ **новые файлы данных ОБЯЗАНЫ попасть в архив деплоя**: `knowledge_base/pp719/
  fragmented_requirements.json` и `inherited_requirements.json`. Без них R29 и наследование R6
  **молча выключатся** — модули отдают пусто при отсутствии файла. Это ровно та ошибка, что уже
  была с `classifiers/*.tsv` в T9;
- ⚠ **тег ДО деплоя** (правило R18);
- переиндексация на VM (`load_kb.py`) — ради R28/R9;
- `load_rules_kb.py` / `seed_cases.py` / `backfill_okpd2_prefixes.py` — **не нужны**, не менялись;
- после деплоя: e2e снаружи (стрим + фолбэк, лимиты 429), затем FF `main`/`prod`.

### 4. Контрольная волна тестирования — главный шаг к гейту

Всё, что делалось в этой сессии, меряется одним: **повторным замером приёмки**. Целевой объём —
не менее 60–80 оценённых ответов. Волна R-A ревью (целостность метрики, дисклеймер, честный дефер)
закрыта именно ради того, чтобы этот замер нельзя было оспорить.

## Среда / как продолжить

- Локальный Qdrant: `Start-Process 'C:\Program Files\Docker\Docker\Docker Desktop.exe'` → контейнер
  `qdrant` поднимется сам. Проверка: `curl http://localhost:6533/collections`.
- Тесты (офлайн, без Qdrant и ключа): `.venv/Scripts/python.exe -m unittest discover -s tests`
- Диагностика данных: `.venv/Scripts/python.exe scripts/diag_orphan_requirements.py`
  (`--fragments` / `--inheritance` перегенерируют файлы данных детерминированно).
- Бэкап с проверкой: `python scripts/backup_db.py --verify <файл>`
- ⚠ Сеть рваная (DPI): длинные коннекты к DeepSeek/GitHub/SSH рвутся — ретраи 3–5 попыток.
- ⚠ Windows + кириллица: `PYTHONUTF8=1 PYTHONIOENCODING=utf-8` для скриптов.
- ⚠ После `/graphify .` проверять `graphify-out/.graphify_root` — скилл пишет туда POSIX-путь,
  который ломает автообновление графа (см. `CLAUDE.md`).
