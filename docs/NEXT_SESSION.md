### Три вывода, которые дороже самих правок

⚠ **Диагностический инструмент врал, и это чуть не увело в другую сторону.** Первая проба

⚠ **Правило трёх прогонов относится и к самому детерминизму.** Четыре замера на НЕИЗМЕННОМ коде
дали 0.80 / 0.60 / 0.90 / 0.60; три подряд — **0.83 ± 0.05** против исходных 0.80, то есть

⚠ **Две «находки» оказались артефактами измерения.** Коллизия методичек воспроизводится только

уточняющие ответы — то самое поведение, которое правило 1г ПРЕДПИСЫВАЕТ. Оптимизируй по ней — и
система начала бы называть баллы по неподтверждённой позиции.

### Долги

* **Детерминизм 0.83 ± 0.05** при пороге гайда 0.95. Понижать `POINTS_TABLE_MIN` бесполезно:
  у всех нестабильных запросов на целевой позиции 0–6 балльных операций, а плавающие числа
  приходят из **порогов соседних позиций-кандидатов**, которые модель то упоминает, то нет.
  Дальше — либо запретить числа из непрофильных кандидатов (нужен замер), либо признать порог
  недостижимым.

* **`gs_natural`** — собирается из данных волны скриптом, как только она пройдёт.
