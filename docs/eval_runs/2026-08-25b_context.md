# Размер контекста (K6)

```
==============================================================================
РАЗМЕР КОНТЕКСТА — 42 in-scope кейсов
==============================================================================
  средняя длина  = 4934 символов
  МЕДИАНА        = 3852 символов   ← среднее уводят мега-продукты
  минимум / максимум = 2137 / 18681
  доля ХВОСТА нецелевых кандидатов = 0.33   (блок есть у 42 из 42 кейсов)

⚠ Доля 0.00 при непустом контексте означает НЕ «хвоста нет», а что маркер 'ПРОЧИЕ КАНДИДАТЫ ОКНА' больше не совпадает с промптом — проверить, а не радоваться.
```
