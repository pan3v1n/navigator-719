Кейсы 43 и 46 с 25.08 проходят: в промпте появился шаблон строки «**Позиция:** «<наименование раздела>», …».
Остаток — не поведение, а данные и проверка.

У трёх разделов из 29 к имени в данных приклеено лишнее:
- маркер сноски: IX «Продукция радиоэлектроники **<5>**», XVIII «Продукция судостроения **<9>, <9(1)>**»;
- редакционная пометка: XXIX «… **(в ред. Постановления … N 2146)**», через неразрывные пробелы.

Это создало два дефекта:

1. **Дефект оракула.** Сверка «полное название дословно» засчитывала атрибуцию только ответу, который повторил
   хвост. Кейс 23 называл раздел верно и проваливался 3 из 3. Кейс 45 провалился там, где модель повторила хвост,
   но с обычными пробелами вместо неразрывных.
2. **Дефект ответа.** Контекст подавал модели имя раздела с хвостом, и модель копировала «(в ред. Постановления …
   N 2146)» в имя раздела в ответе. Пользователь видел служебную пометку как часть названия.

## Правки — раздельно, как требует задача

**1. Оракул** (`scripts/eval_answers.py`, отдельный коммит). Перед сверкой маркеры сносок, пометка «(в ред. …)» и
NBSP снимаются. Нормализация своя, рантайм не вызывается (урок `O3`).

Замер на тех же 12 ответах: **старая метрика 8 / 12 → новая 12 / 12**. Ответы те же, поменялась только проверка.
Отрицательный контроль: часть имени («Продукция и оборудование …») по-прежнему не считается атрибуцией.

**2. Контекст** (`retriever.section_name` / `section_footnotes`). Модель, панель «Источник» и реранкер получают
чистое имя раздела: `(раздел «Продукция радиоэлектроники»; сноски раздела: <5>)`. Маркер сноски идёт отдельной
пометкой, чтобы указатель на неё не пропал. `Hit.section_title` остаётся сырым: это данные, их читают замеры.

Изменились имена ровно трёх разделов (IX, XVIII, XXIX), остальные 26 побайтно те же. Тест-контракт: имя, которое
контекст показывает модели, оракул принимает для каждого из 29 разделов.

## Замер после правки контекста

Кейсы 23, 43, 45, 46 — по 3 прогона; контроль XVIII («требования к спасательным шлюпкам») — 2 прогона.

| | до | после |
|---|---|---|

Мутации проверены: оракул без снятия маркеров — 2 провала теста; контекст с сырым именем — 1 провал.
