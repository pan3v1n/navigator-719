# Выкатка — эталонный скрипт (`O2` #100)

Раньше скрипт выкатки жил вне репозитория (`D:/navigator-deploy/<дата>/deploy_<тег>.sh`) и
писался заново копированием предыдущего. **Три релиза подряд источником дефекта был сам скрипт**,
и каждый раз урок переживал сессию только если его вручную перенесли в чек-лист:

| Когда | Что сломалось | Класс |
|---|---|---|
| 14.08 | обрыв ssh плодил второй `nohup` — четыре параллельные выкатки положили SSH на полчаса | нет `flock` |
| 18.08 | `backup_db.py --verify` без имени файла печатал usage, **копия не создавалась** — и так во всех прошлых выкатках | шаг-фикция |
| 20.08 | в контейнере `qdrant` нет `curl` → `snapshots/recover` не уходил; упавшая проверка **не останавливала** выкатку | предохранитель отчитался, не сработав |

Теперь скрипт один, лежит здесь, правки накапливаются и закреплены `tests/test_deploy_script.py`.

## Состав

```
scripts/deploy/
├── deploy.sh                  ← эталонный скрипт, один на все релизы
├── releases/<тег>.env         ← профиль релиза: тег, счётчики коллекций, маркеры, снапшот
└── checks/
    ├── common/*.py            ← проверки рантайма, обязательные на КАЖДОМ релизе
    └── <тег>/*.py             ← проверки, специфичные для релиза
```

⚠ **Почему `checks/common` отдельно.** Однажды найденный дефект не должен вернуться незаметно.
Пока проверки жили в скрипте очередного релиза, они умирали вместе с ним: `D12` проверялась на
`test11` и исчезла в `test12`. Сейчас в `common` шесть проверок — иерархия ОКПД2 (`D12`),
закупочный порог не выдаётся за общий (`K2`), два графика прим. 17, ступени вместо абзаца прозы,
величина вместо предлога «от», год закупочного порога.

## Как выкатывать

1. Собрать пакет: `navigator-719-<тег>.tar.gz`, `SHA256SUMS.txt`, при необходимости снапшот
   коллекции `*.snapshot.gz`. **Положить туда же `scripts/deploy/`** — скрипт ищет `checks/`
   рядом с собой.
2. Завести профиль `releases/<новый-тег>.env` (копией предыдущего) и **проверить его сухим
   прогоном, не трогая бой**:

   ```bash
   ./deploy.sh --release releases/v0.5.0-testN.env --dry-run
   ```

3. Скопировать пакет на VM, запустить из каталога пакета:

   ```bash
   ./deploy.sh --release releases/v0.5.0-testN.env
   ```

4. **Читать код возврата, а не последнюю строку.** `0` — все проверки прошли; `1` — выкатка
   состоялась, но проверки провалены (разбирать выше по логу, закрытой не считать); `2` — ошибка
   профиля или аргументов, до боя дело не дошло.

Переменные окружения: `PKG` (каталог пакета, по умолчанию текущий), `APP` (рабочая копия на VM,
по умолчанию `~/navigator-719`), `DOCKER` (по умолчанию `sudo -n docker`), `LOCK`.

## Профиль релиза

```bash
TAG="v0.5.0-test12"
EXPECT=([pp719]=1377 [pp719_rules]=311 [verified_cases]=12)   # расхождение = провал
SNAPSHOT=""                    # пусто = рантаймовая выкатка, корпус не трогаем
MARKERS=( "файл|шаблон|описание" ... )        # что ОБЯЗАНО быть в распакованном коде
ANTI_MARKERS=( "файл|шаблон|описание" ... )   # чего быть НЕ должно (старая копия)
```

⚠ **Шаблон маркера обязан ловить ОПРЕДЕЛЕНИЕ, а не упоминание** (`^def foo`, `^_CONST_RE`).
18.08 `grep` по имени удалённой константы поймал её в комментарии, объясняющем удаление, и
остановил ВЕРНУЮ выкатку; `\d` нашёл «цифру» в слове «ОКПД2». Предохранитель, бьющий по верному
коду, дороже отсутствующего: он заставляет усомниться в правке.

⚠ **`SNAPSHOT` заполнять, когда изменился СОСТАВ записей корпуса.** `sync_payloads.py` приводит
payload существующих точек, но лишние не удаляет — единственная форма правки, которую он не
выполняет.

⚠ **Секретов и адресов в профиле нет.** Всё, что зависит от машины, приходит окружением.
