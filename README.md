# 🧭 Навигатор ПП РФ №719

![Статус](https://img.shields.io/badge/V1-MVP%20готов-success)
![Python](https://img.shields.io/badge/Python-3.12-blue)
![Stack](https://img.shields.io/badge/RAG-Qdrant%20%2B%20e5%20%2B%20DeepSeek-orange)
![RF-first](https://img.shields.io/badge/инфраструктура-РФ--доступна-informational)

AI-помощник для **Курской торгово-промышленной палаты**. По описанию продукции или коду
ОКПД2 находит применимую позицию в приложениях к **Постановлению Правительства РФ №719**
(подтверждение производства промышленной продукции в РФ), показывает требования к
локализации, баллы и порог, формирует чек-лист документов.

> ⚠️ **Принцип продукта:** система выдаёт **предварительный анализ**, а не заключение.
> Окончательный вердикт всегда за уполномоченным экспертом ТПП. Это снижает нагрузку на
> экспертов и ускоряет прохождение процедуры для предприятий, не подменяя экспертизу.

## Как это работает

```
        Запрос: «производим прицепы для легковых авто»  (+ ОКПД2 29.20.23)
                                  │
                                  ▼
        ┌───────────────────────────────────────────────────────┐
        │  Гибридный поиск в Qdrant (1602 позиции 719)           │
        │   • dense  — multilingual-e5-large (1024d, семантика)  │
        │   • sparse — BM25 (точные термины и коды)              │
        │   • RRF-слияние + буст по коду ОКПД2                   │
        │   • приоритет кейсов эксперта (коллекция verified_cases)│
        └───────────────────────────────────────────────────────┘
                                  │  топ-N позиций + кейсы
                                  ▼
        ┌───────────────────────────────────────────────────────┐
        │  DeepSeek (deepseek-chat) — ответ СТРОГО по контексту  │
        │   позиция · требования/баллы · что уточнить · источник │
        │   + обязательная пометка «предварительный анализ»      │
        └───────────────────────────────────────────────────────┘
```

База знаний 719 заранее структурирована в JSON (9 разделов приложения, **1602 вида
продукции**) и проиндексирована в Qdrant — на запрос модель не парсит закон заново.

## Быстрый старт

```bash
git clone https://github.com/pan3v1n/navigator-719.git
cd navigator-719
py -3 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env          # вписать DEEPSEEK_API_KEY
```

```bash
# 1) поднять Qdrant (Docker Desktop) и проиндексировать базу (разово)
docker run -d --name qdrant --restart unless-stopped -p 6333:6333 -v D:/qdrant_storage:/qdrant/storage qdrant/qdrant
.venv\Scripts\python scripts\load_kb.py

# 2) запустить интерфейс
.venv\Scripts\python -m streamlit run frontend\streamlit_app.py      # → http://localhost:8501
```

> 💡 При первом `load_kb.py` скачивается модель эмбеддингов **e5 (~2 ГБ)** с HuggingFace.
> На нестабильной сети / из РФ: пакет `hf_xet` (уже в зависимостях) даёт устойчивую
> чанковую докачку; либо зеркало `HF_ENDPOINT=https://hf-mirror.com`; либо скачать модель
> вручную в `models/` и указать путь в `EMBEDDING_MODEL`. Подробности — в [SETUP.md](SETUP.md).

📘 Подробно: **[docs/LAUNCH.md](docs/LAUNCH.md)** · настройка с нуля — **[SETUP.md](SETUP.md)**

### Пример через API

```bash
.venv\Scripts\python main.py        # FastAPI → http://localhost:8000

curl -X POST http://localhost:8000/navigate \
     -H "Content-Type: application/json" \
     -d '{"query":"производим прицепы для легковых авто","okpd2":"29.20.23"}'
```

Ответ содержит: `answer` (разбор), `sources` (позиции 719 с разделом, кодами, операциями,
привязкой), `checklist` (документы), `disclaimer`. Интерактивная схема — `/docs`.

## Стек

| Слой | Технология | Почему |
|---|---|---|
| LLM | **DeepSeek** (`deepseek-chat`) | API доступен из РФ, дёшев, хорош на юридическом русском |
| Эмбеддинги | **multilingual-e5-large** (локально) | без внешних API, бесплатно, 1024d |
| Sparse | **BM25** (локально, mmh3 + Snowball) | точные термины и коды; без скачивания моделей |
| Vector DB | **Qdrant** (Docker) | open source, РФ-доступен, гибридный поиск |
| Backend | **FastAPI** (Python 3.12) | async, авто-документация |
| Frontend MVP | **Streamlit** | быстрый UI без фронтенд-разработки |

Весь стек — RF-доступный и self-hosted; единственный внешний вызов — DeepSeek API.

### Стоимость

Платный только вызов DeepSeek (эмбеддинг и поиск — локальные, бесплатные). Один запрос ≈
**3 000 токенов ≈ $0.0013 ≈ ¥0.009 ≈ ₽0.11** (~11 копеек), то есть **~₽110 за 1000 запросов**.
Постоянных расходов на запрос нет. Подробный расчёт и сметы по фазам — в [docs/BUDGET.md](docs/BUDGET.md).

## Граф знаний кодовой базы (для разработчиков)

Для навигации по проекту подключён [graphify](https://github.com/safishamsi/graphify) —
он превращает код и документацию в **запрашиваемый граф знаний**: god-узлы (ядро архитектуры),
сообщества и **мосты doc→code** (концепт из доков → конкретная функция). Удобно, чтобы
быстро понять устройство системы, не грепая файлы.

- **Покрытие:** весь Python-код (tree-sitter AST) + документация проекта, связанные
  doc→code-мостами. Текст ПП №719 не входит — он живёт в Qdrant для RAG.
- **Где смотреть:** `graphify-out/GRAPH_REPORT.md` (отчёт), `graphify-out/graph.html`
  (интерактивно), либо `graphify query "<вопрос>"`.
- **Локальный:** `graphify-out/` в `.gitignore` — в репозитории не хранится.

```bash
pip install graphifyy        # разово
# в Claude Code:
/graphify .                  # собрать/обновить граф (автообновляется и на каждом коммите)
```

> На Windows перед ручными вызовами: `set PYTHONUTF8=1` (в корпусе кириллица).

## Принципы

- **AI — черновик, эксперт — вердикт.** Каждый ответ содержит пометку о предварительном характере.
- **Петля обучения.** Ошибки/разъяснения эксперта → `knowledge_base/cases/` → переиндексация
  (`seed_cases.py`). Похожие запросы начинают учитывать проверенный кейс с приоритетом — точность
  растёт без дообучения модели.
- **RF-first.** Никаких зависимостей от заблокированных в РФ сервисов.
- **Portable.** Весь контекст в репозитории ([CLAUDE.md](CLAUDE.md)) — работу можно продолжить на любом ПК.
