# Навигатор ПП РФ №719

AI-сервис для Курской торгово-промышленной палаты.  
Помогает предприятиям разобраться в требованиях Постановления Правительства РФ №719
о подтверждении производства российской промышленной продукции.

## Что умеет сервис

- **Навигатор** — по описанию товара или коду ОКПД2 находит применимую группу из приложений к ПП №719, показывает минимальный балл и ключевые требования
- **Чек-лист** — формирует список необходимых документов под конкретную группу товаров
- **Валидатор** — проверяет загруженные документы на комплектность (V2)
- **Генератор актов** — формирует черновик акта экспертизы ТПП под подпись эксперта (V3)

> **Важно:** все ответы системы — предварительный анализ. Финальный вердикт всегда остаётся за уполномоченным экспертом ТПП.

## Стек

| Слой | Технология |
|---|---|
| LLM | DeepSeek V3 (API доступен из РФ) |
| RAG | LlamaIndex + Qdrant |
| Backend | FastAPI (Python 3.11+) |
| Frontend MVP | Streamlit |
| База данных | SQLite → PostgreSQL |
