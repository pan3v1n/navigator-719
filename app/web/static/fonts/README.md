# Шрифт Inter Tight

Файлы `inter-tight-*.woff2` — шрифт **Inter Tight** (переменный, начертания 400–600), подмножества
кириллица, кириллица-расширенная, латиница, латиница-расширенная. Взяты из макета лендинга
(Claude Design, дизайн-система TPPDesignSystem) и лежат локально, чтобы страница не зависела от
внешних CDN.
